# ITP Accelerating Program — Website Export

Static, self-contained website for the 4 featured bio startups. No build step, no dependencies — just plain HTML/CSS.

## Files

- `index.html` — main hub page (company selector)
- `beyondmedicine.html` — Beyond Medicine Co., Ltd.
- `imitar.html` — IMITAR Science Inc.
- `inexoplat.html` — INEXOPLAT, Inc.
- `jeongjin.html` — Jeongjin Bioscience Co., Ltd.
- `assets/` — all images used across the site

## How to publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload all files in this folder (keep `assets/` as a subfolder — same structure).
3. In the repo, go to **Settings → Pages**, set Source to your main branch, root folder.
4. GitHub will give you a live link like `https://<username>.github.io/<repo-name>/` — that's your QR code target.

The QR code should point to `index.html` (i.e. the base repo URL above).
